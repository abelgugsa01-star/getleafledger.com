What the form is actually asking

TTB Form 5210.5, Report – Manufacturer of Tobacco Products or Cigarette Papers and Tubes, is a monthly inventory movement statement. For every class of product you make (cigarettes, cigars, chewing tobacco, snuff, pipe tobacco, roll-your-own, cigarette papers and tubes), it wants the same arithmetic:

Opening
On hand at the start of the month — which must equal last month's closing figure.
Additions
Manufactured, received in bond from other factories, returned to bond.
Removals
Removed tax-paid, removed without payment of tax (export, in-bond transfers), used in manufacture, destroyed, lost.
Closing
On hand at month-end — and it has to equal the physical count you can support.

Opening + additions − removals = closing. If it doesn't, the report is wrong somewhere, and the tax due (which follows the tax-paid removals) is wrong with it. Importers report the same movements for imported product on Form 5220.6. FDA's user-fee submission (Form 3852) uses the same removal figures, so an error here shows up in two agencies' records.

This guide describes a bookkeeping routine. It is not legal or tax advice. The forms, their instructions and 27 CFR Part 40 govern; confirm the current revision of each form on TTB.gov before relying on any line description here.

The records behind every line

27 CFR Part 40 requires manufacturers to keep records that support the report — and TTB examines the records, not the form. Each report line should trace to a source you can produce:

Report figureSource recordWhat has to agree
ManufacturedProduction records by class and dateSum of production for the month, by class; units consistent (pounds, sticks, count)
Received in bondTransfer-in documents from the shipping factoryEvery receipt matches a transfer document with the other permittee's number
Removed tax-paidShipping / sales records, tax computationQuantities × rate = tax reported on the return; dates fall in the period
Removed without payment of taxExport documents, in-bond transfer-out recordsEach removal has the required proof (export evidence, receiving permittee)
Destroyed / lostDestruction notices, loss claimsSupervised or approved as the rules require; no "balancing" losses
Closing on handPhysical inventory countCount agrees with book closing; differences explained, not absorbed

Keep the unit of measure consistent across a class for the whole month. A production log in pounds and a shipping log in cases will reconcile only if the conversion factor is written down and applied the same way every time.

The reconciliation to run before you sign

  1. Carry-forward check. This month's opening for every class equals last month's filed closing. If you corrected last month, the correction has to be visible, not silently rolled in.
  2. Book roll-forward. Opening + manufactured + received + returned − every removal category = book closing, per class. Do it in exact arithmetic, not a spreadsheet that rounds.
  3. Physical-to-book. Compare book closing with the counted inventory. A difference is a finding: overage, shortage, a miscoded removal, or a count error. Name it and resolve it; do not book a loss to make the numbers meet.
  4. Tax tie-out. Tax-paid removals × the rate for each class equals the tax on your return for the same period. Any difference is either a rate table problem or a period cut-off problem.
  5. Document completeness. Every in-bond receipt, in-bond removal, export and destruction has its supporting document on file for the month. A missing document is an exception, even if the quantity is right.
  6. Cross-form consistency. The removal figures you give FDA on 3852 are the same figures on 5210.5. Two agencies, one set of numbers.
The reconciliation should produce the same result every time it is run on the same records. If a re-run gives a different answer, something in the process — a manual adjustment, a rounding, a stale mapping — is not being recorded.

The errors that show up in examinations

  • Opening ≠ prior closing. Usually a correction made after filing and never reported.
  • Unit mix-ups. Pounds vs. units, cases vs. sticks, especially when a supplier's paperwork changes format.
  • Period cut-off. A removal shipped on the 31st, invoiced on the 1st, and reported in the wrong month — so the tax is in the wrong month too.
  • Balancing losses. A "loss" entered to make book equal count, with no notice or claim behind it.
  • Missing transfer documents. The quantity is right but the in-bond paperwork that makes it tax-free is not on file.
  • Class misassignment. A product reported under the wrong class, which changes the rate and the tax.

Month-end checklist

  • Opening balances per class equal last month's filed closing.
  • Production, receipts and returns recorded for the full month with consistent units.
  • Every removal categorised: tax-paid, without payment of tax, used in manufacture, destroyed, lost.
  • Book roll-forward computed per class; arithmetic exact.
  • Physical count taken and compared with book closing; every difference explained.
  • Tax on tax-paid removals agrees with the return.
  • Supporting documents on file for every in-bond, export and destruction entry.
  • FDA 3852 figures match 5210.5.
  • Draft reviewed by the responsible officer; signed copy and evidence package retained.

Questions people ask

Do I still file if there was no activity?

Yes — a report with zeros is different from a missing report. An explicit zero-activity declaration is a fact; a blank is a gap.

How long do I keep the records?

Part 40 sets a minimum of three years from the date of the report (TTB can extend it). Keep the source records, the reconciliation and the signed report together for the whole period.
